# paschoalick.com

Landing site for paschoalick — open-source AI infrastructure in Java & Node-RED.

## Tools

- **Agent Server** — OpenAI Assistants-compatible API you host (Java 21 · Spring Boot · LangChain4j)
- **MCP Tools for Node-RED** — plug any Model Context Protocol server into Node-RED
- **Node-RED on Railway** — one-click Node-RED template with persistent flows

## Deploy

This is a static site (`index.html`). Deploy it anywhere that serves static files:

- **GitHub Pages** — Settings → Pages → deploy from the `main` branch
- **Railway / Vercel / Netlify** — point at the repo; no build step needed
