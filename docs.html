Quick start

Run the Agent Server and its playground locally with Docker Compose. You need Docker with Compose v2 and an API key for at least one LLM provider.

1. Configure

Copy the template. One .env at the root serves the backend, the frontend and Compose.

cp .env.example .env

OPENAI_API_KEY=sk-...
AGENT_API_KEYS=$(openssl rand -hex 24)
AGENT_API_KEY=<same value>
# optional
OPENROUTER_API_KEY=sk-or-...

2. Start

docker compose up --build
# playground → http://localhost:3000
# API        → http://localhost:8080

3. Point your client at it

Clients of the OpenAI Assistants API only change the base URL, the key and the assistant_id.

curl -s -H "Authorization: Bearer $KEY" \
  http://localhost:8080/health
# {"status":"UP"}
With the default AGENT_STORE=memory, threads and runs are lost on restart. Set AGENT_STORE=postgres and DATABASE_URL to keep everything.
